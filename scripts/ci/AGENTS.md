# FLOW CI support

## Purpose

Own whole-file test inventory and immutable distribution verification.

## Local Contracts

Assign every discovered repository test to exactly one suite.
Run all applicable suites without filters or skips.
Qualify both SDK languages through process boundaries and isolated installed consumers.
Host containment and native clients remain Jig responsibilities.
Read npm archive manifests using a local filename and working directory.
Absolute Windows drive paths must never enter tar's remote-host syntax.

After accepted npm publication, poll exact registry integrity for up to five minutes.
Only missing metadata permits waiting. Conflicting bytes or registry access failures must fail immediately without republishing.

## Verification

Run `node --test scripts/ci/*.test.mjs` and `just test-release`.
Workflow contract tests parse YAML 1.2 and check GitHub trigger keys and registry environments.
